Brix

Brix is the .compiler build language (makefile meets build.yml). stwc build runs it.

Grammar (EBNF)

file  = "brix" NUMBER ";" { decl } ;
decl  = "var" ID "=" STRING ";" | "default" ID ";" | "task" ID "{" { step } "}" ;
step  = "need" ID ";" | "run" STRING ";" | "echo" STRING ";" | "lash" STRING "->" STRING ";" ;

Keywords: brix var task need run echo lash default. $name expands vars, then environment variables. run uses sh -c in the project directory. Comments: // and /* */.

Example

brix 1;
var name = "hello";
task prep  { echo "building $name"; run "mkdir -p build"; }
task build { need prep;
  lash "compileinstruction/hello.int" -> "build/app.pkg"; }
default build;

lash only accepts a .int file located at PROJECT/compileinstruction/NAME.int.
