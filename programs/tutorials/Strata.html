Strata

Strata is the tiny markup/config language for menus and the setup flow. Tools: stw strata check|dump|labwc FILE.

Grammar (EBNF)

file = { node } ;
node = ID { arg } [ "->" ID [ "(" [ arg { "," arg } ] ")" ] ] ( ";" | "{" { prop | node } "}" ) ;
prop = ID ":" arg ";" ;
arg  = STRING | NUMBER | ID ;

Example

menu root-menu "Stratum" {
  menu new "New" {
    item "Folder" -> run("stratum-new", "folder");
  }
  sep;
  item "Terminal" -> run("foot");
}

Note: write a space before -> (identifiers may contain "-").
