Lash

Lash is the .int instruction language (linker.ld-like): what goes into the app .pkg and where.

Grammar (EBNF)

file    = { stmt } ;
stmt    = "PACKAGE" "(" STRING "," STRING ")" ";"
        | "ENTRY" "(" STRING ")" ";"
        | "EXCLUDE" "(" STRING ")" ";"
        | "SECTIONS" "{" { section } "}" ;
section = ID [ NUMBER ] ":" "{" { STRING "->" STRING ";" } "}" ;

NUMBER may be octal: 0o755. Source paths may use * (last path part) or name a directory. A target ending in / is a directory.

Example

PACKAGE("hello", "1.0.0");
ENTRY("bin/hello");
EXCLUDE("share/*.txt");
SECTIONS {
  .bin  0o755 : { "src/hello.sh" -> "bin/hello"; }
  .data 0o644 : { "assets/*" -> "share/"; }
}
